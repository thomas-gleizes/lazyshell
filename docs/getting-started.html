Getting started

Install

Prebuilt binaries (Linux and macOS, amd64/arm64) are published on each GitHub release. The install script downloads the latest one, verifies its SHA-256 checksum and installs it in ~/.local/bin.

curl -fsSL https://raw.githubusercontent.com/thomas-gleizes/lazyshell/main/install.sh | sh
VariableEffect
LAZYSHELL_INSTALL_DIRInstall directory. Default: ~/.local/bin.
LAZYSHELL_VERSIONTag to install, e.g. v0.2.0. Default: latest release.

From source

Requires Rust (edition 2024). Unix only (Linux and macOS), because the daemon talks over a Unix socket.

git clone https://github.com/thomas-gleizes/lazyshell.git
cd lazyshell
cargo install --path .
lazyshell --help

Update

lazyshell update                 # latest release
lazyshell update --version v0.2.0

Running daemons keep the old version until you run lazyshell down then lazyshell up.

Quick start

Create a lazyshell.yml at the root of your project:

sessions:
  - name: api
    group: backend
    cwd: ./api
    command: cargo run
    autostart: true
  - name: web
    group: frontend
    cwd: ./web
    command: npm run dev
    env:
      PORT: "5173"

Then run, from anywhere inside the project:

lazyshell

lazyshell looks for lazyshell.yml (or lazyshell.yaml) in the current directory, then in its parents up to your home directory. You can also pass a file or a directory: lazyshell path/to/dir. It starts the project daemon in the background if it is not already running.

Outside any project (no lazyshell.yml found), lazyshell opens the TUI on a daemon that is already running (the projects panel lets you switch between them) and never starts one. With no daemon running it prints a message and exits.

Press ? in the TUI for the key list, q to leave it (sessions keep running) and Q to stop everything.
