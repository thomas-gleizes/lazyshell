How it works

  • One daemon per project, identified by the absolute path of its config file.
  • The daemon listens on a Unix socket under $XDG_RUNTIME_DIR/lazyshell/ (or /tmp/lazyshell-<uid>/), in a directory with mode 0700, so other users cannot reach it.
  • Each session runs in its own pseudo-terminal; the output panel is a terminal emulator, so colours and full-screen programs render correctly.
  • With --auto-exit (what the TUI uses), the daemon exits on its own once no session is active or waiting for its dependencies, and no client is connected. lazyshell up starts it without that flag, so it runs until down.
  • Stopping a session sends SIGTERM, then SIGKILL after 10 s.

Platforms

Linux and macOS, amd64 and arm64. Windows is not supported (Unix sockets and PTYs).
