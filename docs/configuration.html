Configuration

Project file (lazyshell.yml)

KeyWhereDescription
shellrootShell used to run commands. Default: $SHELL, else /bin/sh.
env_fileroot, sessionA path or a list of paths to .env files. Later files override earlier ones; a missing file is ignored.
groupsrootList of - name: … entries declaring session groups.
sessionsrootRequired, at least one session. Names must be unique.
namesessionSession name.
commandsessionCommand to run.
groupsessionGroup the session belongs to, to start/stop/restart several at once.
cwdsessionWorking directory, relative to the folder of the config file.
envsessionInline variables.
autostartsessionStart the session when the daemon starts. Default: false.

Full example

shell: /bin/zsh
env_file: .env
groups:
  - name: backend
  - name: frontend
sessions:
  - name: db
    group: backend
    command: docker compose up postgres
    autostart: true
  - name: api
    group: backend
    cwd: ./api
    command: cargo watch -x run
    env_file: [.env.api, .env.api.local]
    env:
      RUST_LOG: debug
  - name: web
    group: frontend
    cwd: ./web
    command: npm run dev

Environment precedence

Lowest to highest: root env_file < session env_file < session env. Use lazyshell env <name> to print what a session actually receives.

.env syntax

  • KEY=value, with an optional export prefix.
  • # starts a comment.
  • Double-quoted values support the escapes \n \t \" \\; single-quoted values are literal.
  • No variable interpolation.

Reloading

Press L in the TUI or run lazyshell reload. Running sessions are left unchanged; a ~ next to a session means its config changed: restart it to apply the change.

User settings

Stored in $XDG_CONFIG_HOME/lazyshell/config.yaml (default ~/.config/lazyshell/config.yaml):

language: en   # en (default) or fr

An unknown key or value is an error, so typos are not silently ignored.
