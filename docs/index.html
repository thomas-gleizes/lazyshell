lazyshell

lazyshell runs the long-lived processes of a project (dev server, watcher, database, tests…) as named sessions, described in a lazyshell.yml file, and lets you watch them in a two-pane TUI: the session list on the left, the live output of the selected one on the right.

A background daemon owns the sessions. Closing the TUI does not stop them: reopen it later, or drive them from scripts and AI agents with plain CLI subcommands.

v2 is a full rewrite in Rust. The goal changed from a tmux-like terminal multiplexer (Go, versions v1.x) to a project process manager. The Go code and its history live on the legacy/go branch and the v1.* tags.

Features

  • Sessions declared in one YAML file, optionally grouped, with per-session env and .env files.
  • Two-pane TUI: search, scrollback, soft-wrap, fullscreen, mouse selection and copy.
  • One daemon per project: sessions survive the TUI being closed.
  • Each session runs in a pseudo-terminal, so colours and full-screen programs render correctly.
  • Scriptable: status, logs, env, start/stop/restart work without a terminal.
  • Linux and macOS, amd64 and arm64.
