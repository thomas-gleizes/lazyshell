Config editor

One field per option, generated straight from lazyshell's own source (pkg/config) rather than hand-kept in sync — a typo on an enum value or an action id is not something you can make here. The YAML on the right is the only thing that matters: copy it into your user config or your project's lazyshell.yml.

This runs entirely in your browser. Nothing here reads or writes a real file — GitHub Pages serves static files only, and this page has no way to reach your filesystem even if it wanted to. Paste an existing file below to load it back into the form, then keep editing.
