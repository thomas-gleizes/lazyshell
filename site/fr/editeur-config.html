Éditeur de config

Un champ par option, généré directement depuis le code source de lazyshell (pkg/config) plutôt que tenu à jour à la main — une faute de frappe sur une valeur d'énumération ou un identifiant d'action est ici impossible à faire. Le YAML à droite est le seul artefact qui compte : copiez-le dans votre config utilisateur ou votre lazyshell.yml de projet.

Tout se passe dans votre navigateur. Rien ici ne lit ni n'écrit un fichier réel — GitHub Pages ne sert que du statique, et cette page n'a aucun moyen d'atteindre votre système de fichiers même si elle le voulait.
