Configuration

lazyshell config init écrit un fichier entièrement commenté au bon endroit, et lazyshell config show affiche la configuration réellement en vigueur — après que chaque couche a eu son mot à dire — avec les sources dont elle provient. Cette seconde commande est la réponse à « pourquoi mon réglage ne prend pas ».

Où vit le fichier

lazyshell lit son fichier YAML au premier emplacement trouvé :

  1. $LAZYSHELL_CONFIG, s'il est défini
  2. $XDG_CONFIG_HOME/lazyshell/config.yml
  3. ~/.config/lazyshell/config.yml

Un fichier absent n'est pas une erreur : lazyshell tourne avec ses valeurs par défaut. Un fichier partiel n'a besoin de mentionner que les champs qu'il veut surcharger ; tout le reste garde sa valeur par défaut.

Précédence

valeurs par défaut  <  ~/.config/lazyshell/config.yml  <  lazyshell.yml du projet
                    <  variables d'environnement  <  options de ligne de commande

Rien dans un fichier de configuration ne peut empêcher lazyshell de démarrer. Une clé inconnue, une valeur hors bornes, un raccourci illisible ou une couleur inconnue sont signalés sur la sortie d'erreur avant l'ouverture de l'interface, et la valeur par défaut est utilisée à la place — jamais un silence, jamais un refus de démarrer.

Spécifications de touches

Les spécifications suivent la syntaxe de gocui.Parse : un caractère nu (n), ou Ctrl+N, Alt+Space, Tab, Esc.

Les identifiants d'action remappables sont :

new_session, new_session_in_dir, kill_session, delete_session, rename_session, duplicate_session, restart_session, zoom, next_tab, prev_tab, filter_sessions, export_session, toggle_broadcast, jump_next_blocked, select_next, select_prev, cycle_focus, help, quit.

Un identifiant hors de cette liste est signalé plutôt qu'ignoré.

Couleurs

Les couleurs acceptent l'une des trois formes :

  • un nom de couleur ANSI — black, red, green, yellow, blue, magenta, cyan, white, et chacun préfixé de bright (brightblue, …). Ils suivent la palette de votre terminal ;
  • un nom de couleur W3C/CSS (navy, teal, chartreuse, …) ou #rrggbb, pour une couleur précise plutôt qu'un emplacement de palette ;
  • default, pour la couleur par défaut du terminal.

Les deux jeux de noms se recouvrent et se contredisent : en CSS, blue vaut #0000FF, que le terminal montre comme du bleu vif. lazyshell résout d'abord les noms ANSI, donc blue vous donne le bleu ordinaire ; écrivez navy pour celui du CSS, ou brightblue pour l'emplacement vif du terminal.

Exemple complet

Voici ce qu'écrit lazyshell config init — chaque option à sa valeur par défaut, donc vous pouvez supprimer tout ce que vous ne changez pas. 

# ~/.config/lazyshell/config.yml

language: fr
shell: ""
term: xterm-256color
scrollback_size: 10000

sessions_panel_width: 40
sessions_panel_height: 10
portrait_max_width: 84
portrait_min_height: 45

refresh_interval_ms: 30
kill_timeout_ms: 2000

prefix_key: Ctrl+O

keybindings:
  new_session: "n"
  new_session_in_dir: "N"
  kill_session: "x"
  delete_session: "D"
  rename_session: "r"
  duplicate_session: "c"
  restart_session: "R"
  zoom: "z"
  next_tab: "]"
  prev_tab: "["
  filter_sessions: "/"
  export_session: "w"
  toggle_broadcast: "b"
  jump_next_blocked: "B"
  select_next: "j"
  select_prev: "k"
  cycle_focus: Tab
  help: "?"
  quit: "q"

markers:
  bell: "!"
  alt_screen: "#"
  activity: "●"
  broadcast: "+"
  agent_idle: "·"
  agent_working: "…"
  agent_blocked: "‼"
  agent_done: "✓"

scroll:
  page_lines: 0
  half_page_divisor: 2

theme:
  active_border_color: green
  inactive_border_color: default
  selected_bg_color: blue
  pass_through_border_color: red
  tab_active_color: green

clipboard:
  fallback_command: ""

notify:
  fallback_command: ""

window_title:
  enabled: true

mouse:
  enabled: true
  wheel_lines: 3
  forward_to_app: true

perf:
  refresh_interval_ms: 5000

env_tab:
  mask_secrets: true

agent_stats_command: ""
